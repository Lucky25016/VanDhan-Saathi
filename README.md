# 🌿 VanDhan Saathi
### Connecting Forest Produce Collectors with Market Opportunities

VanDhan Saathi is a web-based prototype designed to help
tribal and rural forest-produce collectors explore market
opportunities and organize product listings.

The project aims to support rural livelihoods by making
forest-produce information easier to access.

## 🎯 Problem Statement

Forest-produce collectors may face challenges in accessing
market information, identifying potential buyers, and
comparing selling opportunities.

VanDhan Saathi explores how a simple digital platform could
help address these challenges.

## 💡 Our Solution

VanDhan Saathi provides a prototype interface where users can:

- Explore forest-produce categories.
- Search and filter products.
- View an illustrative price guide.
- Add product listings through a form.
- View and delete listings saved in their browser.

## 🌳 Products Featured

The prototype includes examples such as:

- Mahua Flowers
- Tamarind (Imli)
- Forest Honey
- Sal Leaves
- Harra
- Other Forest Produce

## 🛠️ Technology Stack

- HTML
- CSS
- JavaScript
- Browser Local Storage
- GitHub Pages for hosting

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No separate installation is required for this prototype.

## ⚠️ Current Limitations

- Listings are saved in the current browser only.
- Listings are not shared between different users or devices.
- The prototype does not have a server-side database.
- Price-guide values are illustrative demo values and
  are not verified market prices.
- Real buyer connections and transactions are not yet implemented.

## 🚀 Future Scope

- Shared online listings through a backend database.
- Verified market prices from reliable sources.
- Buyer and seller accounts.
- Local-language support.
- Market and location-based information.
- Notifications about buyer interest and market opportunities.

## 🌍 Social Impact

The project explores how accessible digital technology
could support forest-produce collectors, improve access
to market information, and contribute to rural livelihoods.

Its actual impact would need to be evaluated through
testing with intended users.
