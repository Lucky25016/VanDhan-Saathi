# VanDhan Saathi — Test Cases

## 1. Objective

These test cases are designed to check the main features
of the VanDhan Saathi web application prototype.

## 2. Test Environment

- Device: Desktop or mobile phone
- Browser: Modern web browser
- Application: VanDhan Saathi
- Storage: Browser LocalStorage

## 3. Functional Test Cases

| Test ID | Feature | Test Steps | Expected Result |
|---------|---------|------------|-----------------|
| TC-01 | Website Loading | Open the website | The homepage loads correctly |
| TC-02 | Product Catalogue | View the product section | Product cards are displayed |
| TC-03 | Product Search | Search for a product name | Matching products are displayed |
| TC-04 | Category Filter | Select a product category | Matching category products are displayed |
| TC-05 | Price Guide | Open the price guide | Illustrative demo prices are displayed |
| TC-06 | Add Listing | Fill in and submit the listing form | The application responds to the submitted form |
| TC-07 | Saved Listings | Add a listing and refresh the page | The listing remains if saved successfully in LocalStorage |
| TC-08 | Delete Listing | Delete a saved listing | The selected listing is removed |
| TC-09 | Responsive Layout | Open the website on a phone | Content adjusts to the screen size |
| TC-10 | Empty Search | Clear the search field | The product catalogue returns according to the selected filters |

## 5. Limitations

- These are proposed manual test cases.
- Results must be recorded after actually testing the website.
- LocalStorage data is limited to the current browser.
- The application does not currently provide a shared online database.

## 6. Conclusion

These test cases provide a structured way to evaluate the
main features of the VanDhan Saathi prototype.
